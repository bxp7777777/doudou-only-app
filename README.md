# 豆豆大王的小跟班 · Web 版（Railway 可部署）

一只圆滚滚的小猪（盯喝水吃饭练琴）＋ 一只摇尾巴的小金毛（加油打气）的每日陪伴软件。
**零依赖**：一个 `node:http` 服务 + 原生前端，不需要数据库、不需要打包工具，也没有任何 npm 依赖。

- 前端：原生 HTML/CSS/JS（ES Module），手机优先，可「添加到主屏幕」当 App 用（PWA）
- 后端：静态托管 + `/api/weather` 天气代理（Open-Meteo，免 key，服务端缓存 10 分钟）+ `/api/sync/*` 跨设备同步（落 Railway Volume，可选 `SYNC_SECRET` 服务端口令保护）
- 数据：喝水、打卡、备忘录、周期参数与游戏存档 `ddgame:v1` 默认存在浏览器 `localStorage`；想换手机不丢，就生成一串同步码，服务端 Volume 里保存一份；设置 `SYNC_SECRET` 后所有同步请求都要带口令
- 内置单文件养成小游戏 `public/game.html`：本地进度存 `localStorage` 的 `ddgame:v1`；接入同步码后自动后台推上云端、启动时拉取

## 本地跑

```bash
cd doudou-app
npm start          # 默认 http://localhost:3000
npm run dev        # 改代码自动重启（node --watch）
npm test           # 逻辑烟测 + 渲染烟测
```

想换端口：`PORT=8080 npm start`（Windows PowerShell：`$env:PORT=8080; npm start`）。
同步落盘目录默认 `./data`，想换：`DATA_DIR=./data npm start`。

## 部署到 Railway

**方式 A · 命令行（最快）**

```bash
cd doudou-app
npm i -g @railway/cli
railway login
railway init
railway up
railway domain         # 生成公网域名
```

**方式 B · GitHub 自动部署**

1. 把 `doudou-app` 推到 GitHub（仓库根目录就是这个文件夹，或设 `Root Directory = doudou-app`）。
2. Railway → **New Project → Deploy from GitHub repo** → 选仓库。
3. 构建方式选 **Nixpacks**（默认），它看 `package.json` 就知道是 Node。
4. 启动命令已经写在 `railway.json` 里（`node server.js`），健康检查 `/healthz`。
5. 部署完在 **Settings → Networking → Generate Domain** 生成网址。

### 挂 Volume（跨设备同步必须）

1. 打开服务 → **Settings → Volumes → Add Volume**（或项目页 `+ New → Volume`）。
2. **Mount path 填 `/data`**。
3. 服务 **Variables** 里加一条：`DATA_DIR=/data`。
4. Redeploy（改了变量会自动重启）。

这样重启/重新部署后同步数据还在。没挂 Volume 时服务会把数据写在容器里的 `./data`，**重新部署就没了**（前端仍可用，只是同步记录会丢）。

```text
验一下：
GET  /api/sync/info        → {"ok":true,"storage":"volume"}
POST /api/sync/new         → 拿一串 8 位同步码
POST /api/sync/save        → 存一份快照
GET  /api/sync/load?code=  → 取回来
```

## 跨设备同步怎么用

1. 手机 A 打开 → 右上角 ⚙️ → 「跨设备同步」→ 若服务端要求口令，先在「服务端口令」处填好并保存 → **生成同步码**（例如 `BPQF96E7`）。
2. 手机 B / 电脑打开 → 同一位置填同一道口令、输入这串码 → **用这个码连接**，会先拉取云端数据。
3. 主应用改动（喝水、打卡、备忘录、周期参数、背景、日记）3 秒内自动推送；小游戏 `game.html` 在保存后、切后台、回前台与每 2 分钟自动后台同步一次；另一台打开时以「较新的一份整体快照」为准。
4. 不想同步了点 **断开同步**，本机数据不受影响；游戏设置页也有「立即同步」按钮，战斗/弹窗中不会自动覆盖进度。

- 存储白名单：`dd:` 前缀记录 + 游戏存档 `ddgame:v1`；单值上限 256KB、整包 2MB；非法前缀与超大值服务端直接丢弃。
- 每个同步码对应各自一份云端记录、彼此隔离；同步码是个人记录凭证，服务端 `SYNC_SECRET` 是公开部署时的统一口令层；公开站点务必设置口令，别把码发给外人。
- 同步是整份快照「较新整体覆盖较旧」，不逐条合并；两台设备同时改动会以最后推上去的一份为准，建议日常以一台主设备为主。

## 功能

| 时段 | 出什么 |
| --- | --- |
| 05:00–11:00 | 喝水·上午杯、今天的节奏、早餐、南宁+深圳天气、晨间护肤、今日打卡 |
| 11:00–14:00 | 午餐、喝水、今天的节奏、小日子 |
| 14:00–17:30 | 喝水·午后杯、食堂加餐、练琴·护手、天气、小日子 |
| 17:30–21:30 | 喝水·晚间杯、晚餐、晚间护肤、练琴·护手、今日打卡 |
| 21:30–23:00 | 饮水收尾、护肤、收工催睡、今日回顾、备忘录 |
| 23:00–23:30 | **晚安包**：打卡回顾 ＋ 明日计划（含课表）＋ 睡前故事 ＋ 备忘录 ＋ 晚安 |
| 23:30 之后 | 只留一句催睡，不再发长消息 |

页面：今陪伴 / 小日子 / 每日故事 / 备忘 / 养成（设置在右上角齿轮 ⚙️）。

她自己的设定（改一处全局生效）：
- **学校**：广西艺术学院，三餐在食堂 —— 不推具体菜，只提醒「去食堂、热的、七分饱、别省早饭」。
- **课表**（`public/js/schedule.js`）：默认只是「先按之前记的猜」——周一早十 / 周二没早八、下午空 / 周三早八 / 周四最忙、早八 / 周五大概率早十 / 周末没课。设置页里豆豆可以自己改：每天选「上午没课 / 早八 / 早十」+「下午有课 / 空」+ 一句备注，存进 `dd:schedule`，存了就以她填的为准（首页节奏卡、早餐文案、晚安包次日预告全部跟着变），没填就还按猜的那版，并标「还不确定」。
- **练琴**：练前洗手擦干、别用冷水泡手、练完涂护手霜、指甲修短、30 分钟慢练；打卡里有「练琴30分钟」。
- **天气**：南宁（学校）＋深圳（家里）：温度、体感、区间、湿度、降水概率，再据此出温差/干燥/带伞提醒，不提穿什么。
- **背景**：四张 Q 版插画轮换（贴贴 / 打盹 / 散步 / 点心），默认「每日轮换」每天自动换一张，也能钉住某一张或点「换下一张」；另有宣纸暖粉 / 青竹 / 晨雾 / 晚霞四套素净底色。
- **每日故事**：1000 篇短故事（`stories.js`）按日期轮换、当天固定、连续两次不重复；故事页配套 **1000 条日常笑话**（`jokes.js`）与打卡勋章。
- **小日子**：不只是例假记录。每天一条日记（心情 5 档 / 身体 5 档 / 10 个标签 / 4000 字上限，边写边存），近 14 天日历能翻回去补写，列表可搜索，统计「这个月写了几天 / 连着写 / 总共几天 / 多少字」，一键导出 `豆豆的小日子.md`；周期卡放在最后，参数未知时依旧不推算任何日期。
- **周期**：参数未知时不推算任何日期，只温柔问一次；填了之后按当天现算（周期第几天、距下次、经期剩余、经前 5 天提醒、排卵日≈下次−14 天、易孕期前5后4）。

## 养成小游戏 `/game.html`

单文件 HTML（内联 CSS + JS；宠物 / 小怪 / Boss / 元素图标优先用本地立绘，缺图时自动 emoji 兜底），中文 UI，奶油底＋马卡龙配色。挂机产出 → 抽蛋/升级/进化 → 推主线 & 爬塔 → 更多产出；离线 12 小时封顶按 0.6 系数结算，回来弹窗领取。

- 40 只可收集宠物（基础 20 + 风系 5 + 冰系 5 + 其余 10；稀有度 N4 / R17 / SR14 / SSR5），八属性克制环（火 / 草 / 水 / 光 / 暗 / 土 / 风 / 冰）；另有 16 只野生小怪、10 只章节首领独立档案
- 等级 / 升星 / 两阶进化 / 装备四槽强化 / 技能书 / 亲密度 / 羁绊
- 自动回合制战斗：速度、怒气奥义、暴击、克制、1–3 星结算
- 战斗表现（第一批）：出手前冲 / 施法抬手 / 奥义突进、受击后仰、闪避横移、死亡倒地淡出、待机呼吸、当前行动光圈、主动技名称横幅、飘字分级（暴击·克制·抵抗·治疗·护盾·闪避·MISS）、战斗日志靠类型着色；2 倍速下时长减半，`prefers-reduced-motion` 自动关动画
- 主线章节、爬塔、竞技场、每日 Boss、奇遇事件、每日副本、七日签到；成就共 200 项并含难度档
- 图鉴、成就、转生、装扮、抽蛋概率公示、存档导出/导入
- 存档在 `localStorage` 的 `ddgame:v1`；接入同步码后随主应用一起上云自动后台同步，也仍可在游戏设置里导出/导入 JSON 做本地备份

## 已知边界

- 主页背景是 4 张 AI 生成的 Q 版小猪+小金毛插画（`public/art/bg-ai1.jpg`～`bg-ai4.jpg`，贴贴 / 打盹 / 散步 / 暖饮），由 `public/js/app.js` 的 `DUO_ARTS` 每日轮换、设置里手动切换；`icon-duo.svg` 为站点图标。
- 不挂 Volume 或不设 `DATA_DIR=/data` 就没有持久化：容器重建 → `./data` 清空 → 云端记录丢失（本机 localStorage 仍在）；公开部署务必挂持久盘并设置 `SYNC_SECRET`。
- 同步是整份快照「较新整体覆盖较旧」，没有逐条合并；两台设备同时改会以最后推上去的一份为准；战斗/离线结算弹窗中游戏不会自动拉取覆盖。
- 提醒是「打开页面时按当前时间出对应模块」，不是后台推送。要真推送得接 Web Push 或微信服务号/邮件。
- 天气来自 Open-Meteo 的免费接口，异常时页面会温柔兜底（「小猪没查到，出门前自己看一眼窗外」），不会白屏。
- 内容只做生活提醒：喝水、吃饭、睡觉、练琴、护肤、日期，不推销产品。
